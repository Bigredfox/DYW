Daily Work Log
Where the behavior lives.

Six gentle prompts capture a day's work. A draft keeps unfinished answers; saving creates a completed log. Profile opens drafts or saved weeks and days. Everything stays in this browser.

Follow one action: replacing a saved log

Review → SaveApp.jsx → save
Checks whether confirmation is needed.
→
Confirm → persiststorage.js → saveDraft
Writes the saved log and removes its draft in one snapshot.
→
Show successCompletion.jsx
Appears only after storage succeeds.

If writing fails, review retains the answers and the previous saved log remains intact. There is no server or external log service.

A three-stop reference route

This route points to the finished code. It does not imply an interactive code tour has been completed.

  1. src/App.jsx — search for function save. A saved date first opens OverwriteDialog. Confirmation calls save(true); cancellation returns to review.
  2. src/lib/storage.js — search for saveDraft. It creates a separate snapshot, preserves the original createdAt, removes only the matching draft, and calls writeSnapshot.
  3. src/components/Completion.jsx — the visible result. Back in App.jsx, setScreen('complete') happens after the storage call; a thrown error takes the failure path instead.
See the evidence behind this route

devpost/prd.md → Edit or Replace an Existing Daily Log defines the protection. src/lib/storage.test.js checks the case named “keeps the original saved day and draft on failed replacement, then replaces atomically on retry.” The browser walkthrough checks the visible confirmation behavior.

A practice to reuse

Turn a requirement into an observable result before asking an agent to implement it. Here, “protect the old log” became a concrete condition: a canceled or failed replacement leaves the original saved answers unchanged. The PRD names it, saveDraft implements it, and the storage tests check it.

For a future discard button, first agree on which record disappears and which record must remain. That decision gives the code and verification a clear target.
